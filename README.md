# 🏥 Medical Insurance Cost Estimator

An end-to-end machine learning project that predicts individual annual medical insurance charges from personal and lifestyle attributes, deployed as an interactive **Streamlit** web app.

---

## 📌 Project Overview

Insurers price premiums based on risk factors such as age, BMI, and smoking status. This project explores how those factors drive medical charges, builds regression models to predict them, and wraps the best model in a simple app where a user can enter their details and get an instant estimate, compared against average smoker and non-smoker charges.

**Workflow:** Data cleaning → EDA → feature engineering → model comparison → model export → Streamlit app

## 📊 Dataset

| Feature    | Description                                  |
|------------|----------------------------------------------|
| `age`      | Age of the policyholder (18–64)              |
| `sex`      | Male / female                                |
| `bmi`      | Body mass index                              |
| `children` | Number of dependents covered (0–5)           |
| `smoker`   | Smoker status (yes / no)                     |
| `region`   | Residential region (NE, NW, SE, SW)          |
| `charges`  | **Target**: annual medical charges (USD)     |

- **Raw size:** 2,772 rows × 7 columns, no missing values
- **Duplicates:** 1,435 duplicate rows were identified and removed before modelling

---

## 🔍 Exploratory Analysis: Key Findings

- **Smoking is the strongest driver of cost.** Smokers average ≈ **$32,050** versus ≈ **$8,441** for non-smokers.
- **Higher BMI means higher charges.** Mean charges rise from ≈ $8.9K (underweight) to ≈ $15.6K (obese).
- **Charges are right-skewed** (skew ≈ 1.52), with ~10% of records flagged as outliers by the IQR rule. A `log1p` transform brought skew to ≈ -0.09, so the models are trained on log-charges and predictions are converted back with `expm1`.

---

## ⚙️ Feature Engineering & Preprocessing

- Removed duplicate rows
- Created a `bmi_category` feature (underweight / normal / overweight / obese)
- Log-transformed the target (`log1p(charges)`)
- One-hot encoded `sex`, `smoker`, `region`, and `bmi_category` (`drop_first=True`)

---

## 🤖 Modelling & Results

Three regressors were trained and evaluated on the held-out test set. Metrics are reported on the original dollar scale.

| Model               | R²     | MAE (USD) | RMSE (USD) |
|---------------------|--------|-----------|------------|
| **Random Forest** ✅ | 0.8458 | 2,282.55  | 4,704.65   |
| Gradient Boosting   | 0.7796 | 2,788.81  | 5,623.84   |
| Linear Regression   | 0.5755 | 4,116.73  | 7,805.52   |

The **Random Forest Regressor** (300 trees, `max_depth=6`) performed best and was exported with `joblib` for use in the app.

## 🚀 Running the App Locally

```bash

cd <your-repo-name>
```

**2. Install dependencies**
